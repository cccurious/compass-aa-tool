フォールバック幅 較正ページ v0

仮説「ゲームのフォールバック先 ＝ この端末の OS フォント」の答え合わせをします。 ゲーム実機で幅が確定している文字だけをブラウザで測り、比率が一致するかを見ます。 iPhone または Android のブラウザで開いてください（PC では判定できません）。 結果はスクショを送るか、下の「結果をコピー」を貼り付けてください。

判定基準の端末:

陽性対照（ゲーム実機で非 1.0 と確定している文字・ここが一致すれば理論成立）

iOS では二重罫線 = 0.719・網かけ四角 = 0.875・濃淡 = 0.5 などと実測済み。 ブラウザでも同じ比率が出るなら、ブラウザを測定器としてゲームの幅を予測できます。

幅 1.0 群（ゲーム実機で両端末とも全角と確定している文字）

陰性対照（ゲームのフォントアトラス内の文字・一致しないのが正常）

半角英数はゲーム自身のフォントで描かれるため OS フォントとは別物。 ここまで一致してしまったら「たまたま似たフォント」の可能性を疑う必要があります。

参考（ゲームでは幅 0 ＝ グリフ無しの文字）

ブラウザは別のフォントで補って表示できてしまうことが多いので、判定には使いません。 ブラウザ側の幅だけ記録します。
